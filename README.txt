ARSALAN ALI - PORTFOLIO


What's inside this folder
- index.html            : The complete website (open this file in your browser)
- Arsalan_Ali_CV.pdf    : The "Download CV" button downloads this file
- images/               : Your photo and project screenshots

How to open
Double-click on index.html. You will need an internet connection (Tailwind and fonts are loaded online).

How to deploy online
Upload the entire folder to Vercel, Netlify, or GitHub Pages. Keep the folder structure as it is.

How to change the CV
Replace the old CV with your new CV in this same folder and name it "Arsalan_Ali_CV.pdf".

How to add a new project
1. Put your project screenshot in the images/ folder (e.g., images/my-project.png)
2. Open index.html and search for "const PROJECTS = ["
3. Copy the { ... } block for JobQuestAI, add a comma after it, and paste it
4. Change the title, description, live link, tech stack, etc., and set image: "images/my-project.png"
Any field you leave empty ("" or []) will be automatically hidden.
