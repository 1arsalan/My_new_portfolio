ARSALAN ALI - PORTFOLIO
=======================

Is folder mein kya hai
- index.html            : poori website (ye file browser mein kholein)
- Arsalan_Ali_CV.pdf    : "Download CV" button isi file ko download karta hai
- images/               : aapki photo aur project screenshots

Kholne ka tareeqa
index.html par double click karein. Internet chahiye hoga (Tailwind aur fonts online se aate hain).

Online daalne ka tareeqa
Poora folder Vercel, Netlify ya GitHub Pages par upload kar dein. Folder ka structure waisa hi rakhein.

CV badalna
Nayi CV ko purani ke naam "Arsalan_Ali_CV.pdf" se isi folder mein replace kar dein.

Naya project add karna
1. Project ka screenshot images/ folder mein rakhein (jaise images/mera-project.png)
2. index.html mein "const PROJECTS = [" dhoondein
3. JobQuestAI wala { ... } block copy karein, uske baad comma lagayen aur paste karein
4. title, description, live link, tech waghera badal dein, aur image: "images/mera-project.png" likh dein
Jo field khali ("" ya []) rakhenge wo hissa khud chhup jata hai.
